# Hệ thống Quản lý Sinh viên - DTC245200369

Đề tài 2: Website quản lý sinh viên (CRUD sinh viên, lớp, điểm số).

## Công nghệ
- Ứng dụng: Node.js (Express)
- CSDL: MySQL + phpMyAdmin
- Reverse proxy: Nginx (HTTPS tự ký, security headers)
- Giám sát: Prometheus + Grafana
- Log tập trung: Loki + Promtail
- Triển khai: Docker Compose
